# Project-Euler-Solutions

This is a short repo of my solutions to coding questions from [Project Euler](https://projecteuler.net), in Python.

This repo contains spoilers for solutions, do not view if you plan on completing these in the future.

Each problem has its own file named "Problem_XXX.py"

I aim for efficient solutions, though they aren’t always optimal.

All solutions in this repo are made completely by me with no online reference or AI assistance before or during solving.
